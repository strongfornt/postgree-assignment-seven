
## 1. PostgreSQL কী?
 PostgreSQL একটি ওপেন সোর্স রিলেশনাল ডেটাবেইজ ম্যানেজমেন্ট সিস্টেম (RDBMS), যা SQL এবং উন্নত ডেটা টাইপ ও এক্সটেনশন সাপোর্ট করে। এটি স্থায়িত্ব, ডেটা ইন্টিগ্রিটি এবং উন্নত ফিচারগুলোর জন্য বিখ্যাত।

## 2. PostgreSQL-এ ডেটাবেইজ স্কিমার উদ্দেশ্য কী?
 স্কিমা একটি ডেটাবেইজের ভিতরে একটি আলাদা নামকৃত কাঠামো যা টেবিল, ভিউ, ফাংশন ইত্যাদিকে সংগঠিত রাখে। এটি ডেটাকে শ্রেণীবদ্ধ করে এবং নামের সংঘর্ষ এড়াতে সাহায্য করে।

## 3. প্রাইমারি কি (Primary Key) এবং ফরেন কি (Foreign Key) কী?
- Primary Key: একটি টেবিলের এমন একটি কলাম বা কলামগুলোর সমন্বয় যা প্রতিটি রেকর্ডকে ইউনিকভাবে চিহ্নিত করে।

- Foreign Key: একটি টেবিলে এমন একটি কলাম যা অন্য একটি টেবিলের Primary Key-এর সাথে সম্পর্কযুক্ত, যার মাধ্যমে টেবিলগুলোর মধ্যে সংযোগ গঠিত হয়।

## 4. VARCHAR এবং CHAR এর মধ্যে পার্থক্য কী?
- VARCHAR(n): ভ্যারিয়েবল দৈর্ঘ্যের স্ট্রিং, যেখানে n হলো সর্বোচ্চ দৈর্ঘ্য। এটি শুধুমাত্র যতটুকু দরকার ততটুকু জায়গা ব্যবহার করে।

- CHAR(n): ফিক্সড দৈর্ঘ্যের স্ট্রিং। যদি কম ক্যারেক্টার থাকে, বাকি জায়গা স্পেস দ্বারা পূর্ণ করা হয়।

## 5. SELECT স্টেটমেন্টে WHERE ক্লজের উদ্দেশ্য কী?
WHERE ক্লজ নির্দিষ্ট শর্ত অনুযায়ী ডেটা ফিল্টার করতে ব্যবহৃত হয়। এটি ব্যবহার করে আমরা কেবলমাত্র সেই রেকর্ডগুলো পাই যেগুলো শর্ত পূরণ করে।

## 6. LIMIT এবং OFFSET কী কাজে ব্যবহৃত হয়?
- LIMIT: কতগুলো রেকর্ড রিটার্ন করতে হবে তা নির্ধারণ করে।

- OFFSET: কোন পজিশন থেকে রেকর্ড রিটার্ন শুরু হবে তা নির্ধারণ করে।

## 7. UPDATE স্টেটমেন্ট দিয়ে কীভাবে ডেটা পরিবর্তন করা যায়?
UPDATE কমান্ড ব্যবহার করে টেবিলের বিদ্যমান রেকর্ড পরিবর্তন করা যায়। উদাহরণ:
- UPDATE students SET name = 'Ahsan' WHERE id = 1;

## 8. JOIN অপারেশনের গুরুত্ব কী এবং এটি কীভাবে কাজ করে?
JOIN বিভিন্ন টেবিলের ডেটাকে সম্পর্কিত করে একত্রে দেখাতে সাহায্য করে। উদাহরণ: INNER JOIN একটি টেবিলের কলাম অন্য টেবিলের সাথে মিলিয়ে মিলিত রেকর্ড দেখায়।

## 9. GROUP BY ক্লজ ও এর ভূমিকা কী?
GROUP BY ব্যবহার করে আমরা নির্দিষ্ট কলামের ভিত্তিতে ডেটা গ্রুপ করতে পারি এবং প্রতিটি গ্রুপের উপর অ্যাগ্রিগেট ফাংশন (যেমন COUNT, SUM) প্রয়োগ করতে পারি।

## 10. PostgreSQL-এ COUNT(), SUM(), এবং AVG() কীভাবে কাজ করে?
- COUNT(): রেকর্ডের সংখ্যা গণনা করে।

- SUM(): নির্দিষ্ট কলামের মোট যোগফল বের করে।

- AVG(): নির্দিষ্ট কলামের গড় মান বের করে।

 #### উদাহরণ:

- SELECT COUNT(*), SUM(price), AVG(price) FROM products;
